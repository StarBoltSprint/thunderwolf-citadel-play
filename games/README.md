# Games packages (static)

Playable vessels sealed at the Publishing Gate live here by **Artifact ID**.

```text
games/
  {artifact_id}/
    v1/
      index.html
    v2/
      index.html
```

Example:

```text
games/artifact_smir_7k9x2p/v1/index.html
```

See [docs/ARTIFACT_IDENTITY.md](../docs/ARTIFACT_IDENTITY.md) for minting rules and URL map.

Legacy demos in this folder (`storm-corridor-sprint.html`, `rune-ring-leap.html`) predate Decree #601 IDs and may stay as shared runtimes linked from seed items.
