      Boltverse cover style

      Imagine · Hall standard

      Hall cards use the same visual language: cosmic white wolves, cyan + gold lightning, dark mythic space. Generate with Grok Imagine (or matching tools) using the Pack prompt below — then upload the result.

      • Subject: white / cosmic wolf(s), Pack spirit, citadel, storm — not random stock photos
      • Palette: deep indigo void · cyan lightning · soft gold accents · starlight whites
      • Mood: cinematic game key art, mythic, luminous edges — polished digital painting
      • Format: square 1:1, no text, no watermark, no UI chrome
      • Avoid: photoreal humans, neon vaporwave clutter, meme screenshots, plain photos

      Tip: paste the prompt into Grok Imagine / image gen, download the square cover, then upload it here — or pick a ready Pack cover below.
